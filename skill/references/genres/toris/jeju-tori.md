# 제주토리 — 제주

> 인덱스/공통 주의·비교표는 `00-index.md`. 채보 실곡은 `../minyo/odolttogi.md`(오돌또기).

**권역**: 제주도. 육지와 **다른 독자성**(노동요·의식요 중심, 단순·반복적).

## 구성음·음 기능
- 학자에 따라 **경토리에 가까운 음계**로 보되 **독자적 시김새·진행·종지**를 강조하거나,
  별도 권으로 분류한다. 핵심은 **육지 토리로 환원되지 않는 독자성**.
- ⚠ 자료가 적고 곡별 편차가 크다. **단정하지 말고 실제 제주민요를 직접 분석**해
  음계·중심·종지를 추출하라(작곡가 검증 우선).

## 전형/장단
- **노동 리듬**에 얹힌 단순 반복 음형이 흔하다 — 노 젓는 소리(이어도사나)·맷돌 노래
  (맷돌·방아 노래)·해녀 소리. 메기고 받는 선후창, 반복 구조.

## 대표곡
오돌또기, 이어도사나(해녀 노 젓는 소리), 너영나영, 서우젯소리, 멸치 후리는 소리.

## 정서
섬·바다·노동의 독특함. 육지 5음계의 애조와 다른 결.

## 어울리는 악기
단순 반복 위 가야금·해금의 독자 음형. **과한 산조식 기교는 이질적** — 소박한 반복을
살린다.

## 창작 처방
- 이국적·섬 정서에. **표준 토리(경·남도 등)로 환원하지 마라.** 실제 제주민요 선율을
  직접 참조해 음계·종지를 추출하라(자료가 적으므로 **원곡 분석이 필수**).
- 노동요의 **메기고 받는 반복 구조**를 형식 동력으로 가져올 수 있다.

## 흔한 오해 / 하지 말 것
- ✗ "한국 민요 = 5음계"라는 통념으로 제주 음계를 뭉개기.
- ✗ 자료 부족을 그럴듯한 추정으로 메우기 — 모르면 원곡을 찾아 분석하고, 불확실하면
  그렇게 밝혀라.
