# 육자배기토리 (남도토리) — 전라·경상 서부·충남 일부

> 인덱스/공통 주의·비교표는 `00-index.md`. 채보 실곡은 `../minyo/jindo-arirang.md`
> (진도아리랑). 산조·시나위는 `../sanjo/00-index.md`, `../sinawi.md`.

가장 기교적이고 표현이 짙은 토리. **판소리·남도시나위·산조**의 음악적 토대.
**계면조의 핵.**

## 구성음·음 기능 (남도 계면조의 〈떠는음–평음–꺾는음〉)
- 골격 **미·라·시** (+ 보조 도·높은 미). 세 음의 **기능이 뚜렷**하다:
  - **떠는음 = 미** : 굵고 깊게 떤다(요성). 보통 느리게 시작해 폭을 키운다.
  - **평음(본음) = 라** : 떨지 않고 평평하게 받친다(중심).
  - **꺾는음 = 시** : 위에서 **라로 깊게 꺾어 내린다(퇴성)**. 남도 특유의 "꺾기".
- 이 **〈떠는음–평음–꺾는음〉 3기능**이 남도의 정체성. 음계가 아니라 **이 거동**이 핵심.
  떠는음·꺾는음은 **유동 표현음**이지 화음 구성음으로 고정하면 안 된다.

## 전형 선율 음형
- 미(굵은 요성)에서 출발 → 라로 평하게 → 시로 올라갔다 **시→라로 깊게 꺾어** 내림.
- 종지는 **미**(깊은 떪) 또는 라. 긴 음·종지에 시김새를 몰아 표현을 응축한다.

## 시김새
- **미의 굵고 느린 요성**(폭을 키워가며), **시→라의 깊은 퇴성(꺾음)**. 짙은 농음.
  서도처럼 잘게 떨지 않고 **굵고 느리게** — 한(恨)의 미감.

## 장단 경향
진양조(느림)·중모리·중중모리·자진모리·엇모리. 판소리·산조의 장단 체계와 직결 —
**느림→빠름 한배 점층**(→ `../korean-creative-art-music.md` 3절).

## 무악·기악 연계
남도 무가(씻김굿)·시나위(즉흥 합주)·산조의 뿌리. 즉흥·기교의 정점. 시나위는
`../sinawi.md`, 산조 유파는 `../sanjo/00-index.md`.

## 대표곡
육자배기, 자진육자배기, 흥타령(남도), 진도아리랑, 강강술래, 새타령, 농부가,
까투리타령.

## 발성(성악)
굵고 탁한 **수리성**, 깊은 농음. 한(恨)의 미감. 경기의 맑음·서도의 비성과 정반대.

## 어울리는 악기
해금·아쟁의 울음 같은 글리산도, 대금의 짙은 농음, **가야금/거문고 산조** 어법.
시김새가 들리도록 반주를 비운다.

## 창작 처방
- 한·짙은 애절을 원하면 이 토리. **미 깊은 요성 + 시→라 꺾음**을 긴 음·종지에 배치.
- **반주를 비워** 농현이 들리게(→ 창작 실전 2절). 동시에 여러 성부가 떨면 진흙.
- 산조/시나위 어구는 인용에 그치지 말고 **동기로 변형·발전**시켜 구조에 녹여라.
- 가장 기교적이라 **연주자 역량을 전제** — 무리한 속주 중 깊은 꺾음은 안 산다.

## 흔한 오해 / 하지 말 것
- ✗ 경토리식 절제 — 남도는 깊게 떨고 꺾어야 산다.
- ✗ 떠는음(미)·꺾는음(시)을 화음 구성음으로 고정 — 유동 표현음이다(화음은 골격음에).
- ✗ 메나리와 혼동 — 메나리는 담백한 흘러내림, 남도는 굵고 깊은 떪·꺾음.
