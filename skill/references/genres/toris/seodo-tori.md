# 수심가토리 (서도토리) — 평안·황해

> 인덱스/공통 주의·비교표는 `00-index.md`. 채보 실곡은 `../minyo/susimga.md`(수심가).

**권역**: 평안·황해(서도). 음계보다 **발성과 진행**이 정체성인 토리.

## 구성음·음 기능
- 음계 대략 **레-미-솔-라-도**(이동도). **중심(본청) = 레**(하행 종지가 레로 떨어진다).
  출처는 **레·라를 이중 핵음**으로 보아 '라'는 떨고 '레'로 종지한다고 본다.
- **'라'를 떨고(요성), '도'는 퇴성(꺾어 흘러내림)**으로 처리한다(둘 다 떠는 게 아니다).
  요성은 출처에 따라 **굵고 규칙적**(정가의 떠는 목에 가까움)이다. 선율이 **위에서 아래로
  흘러내려** '레'로 마친다.
- **콧소리(비성)** 섞인 음색이 표지이나, **과도한 비성은 비선호** — 두성과 섞어 맑고 높게.

## 전형 선율 음형
- **높은 음역에서 시작** → '라' 요성(**굵고 규칙적**) → **하행 흘러내림** → 레로 안착.
- 장식이 많고 자유롭다. 상행보다 **하행 지향**이 강하다.

## 시김새
- **'라'의 요성(굵고 규칙적; '솔'과 '라' 사이를 툭툭 끊어 올려 치는 떪) + '도'의 퇴성**.
  하행 글리산도식 흘러내림. 비성(과하지 않게). 정가(가곡·가사·시조)의 떠는 목에 가깝다.

## 장단 경향
수심가는 일정 장단이 약한 **불규칙/무장단**에 가깝고, 엮음수심가는 사설을 촘촘히
엮는다. 난봉가류는 굿거리/볶는타령으로 흥겹게.

## 대표곡
수심가, 엮음수심가, 산염불, 자진염불, 긴아리, 자진아리, 난봉가, 사설난봉가, 배따라기.

## 발성(성악)
두성+비성을 섞어 맑고 높게, 처량하고 애절. 비성이 표지이나 **과도하면 비선호**. 서도색은 발성이 절반이다.

## 어울리는 악기
해금·대금의 **흘러내림 글리산도 + 농현(굵게)**으로 음성을 모사. 콧소리(비성)는
성악에서 — 기악만으로는 농현·하행 글리산도로 근사한다.

## 창작 처방
- 탄식·애상에. 선율을 **높은 데서 시작해 흘러내리게** 설계하고, **'라' 요성(굵고 규칙적)
  + '도' 퇴성**을 표지로. 종지는 **레**로 떨어뜨린다.
- 기악만으로 쓸 땐 해금·대금의 농현(굵게) + 하행 글리산도로 서도색을 낸다.

## 흔한 오해 / 하지 말 것
- ✗ 서도 요성을 '잘고 빠른 떪'으로 단정 — 출처는 **굵고 규칙적**(정가류에 가깝다). '도'는 떠는음이 아니라 퇴성.
- ✗ 또렷한 강박 장단에 가두기 — 수심가류는 무장단·자유 리듬에 가깝다.
- ✗ 중심음을 아무 데나 — 서도는 **레로 흘러내려 종지**한다.
