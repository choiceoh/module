# 수심가토리 (서도토리) — 평안·황해

> 인덱스/공통 주의·비교표는 `00-index.md`. 채보 실곡은 `../minyo/susimga.md`(수심가).

**권역**: 평안·황해(서도). 음계보다 **발성과 진행**이 정체성인 토리.

## 구성음·음 기능
- 음계 대략 **레-미-솔-라-도**(이동도). **중심(본청) = 레**(하행 종지가 레로 떨어진다).
- **위쪽 음(라·도)을 격하게 잘게 떤다**(빠르고 촘촘한 요성) — 남도의 굵고 느린 떪과
  정반대. 선율이 **위에서 아래로 흘러내린다**. '레'에 가서 떨거나 거기서 마친다.
- **콧소리(비성)** 섞인 특유의 음색이 음 기능만큼 중요한 표지.

## 전형 선율 음형
- **높은 음역에서 시작** → 격한 **잘은 떪** → **하행 흘러내림** → 레로 안착.
- 장식이 많고 자유롭다. 상행보다 **하행 지향**이 강하다.

## 시김새
- **라·도의 빠르고 촘촘한 잘은 떪**(서도 특유). 하행 글리산도식 흘러내림. 비성.
  굵고 느린 남도 농음과 혼동 금지.

## 장단 경향
수심가는 일정 장단이 약한 **불규칙/무장단**에 가깝고, 엮음수심가는 사설을 촘촘히
엮는다. 난봉가류는 굿거리/볶는타령으로 흥겹게.

## 대표곡
수심가, 엮음수심가, 산염불, 자진염불, 긴아리, 자진아리, 난봉가, 사설난봉가, 배따라기.

## 발성(성악)
콧소리 섞인 잘은 떨림, 처량하고 애절. **가장 독특한 발성** — 서도색은 발성이 절반이다.

## 어울리는 악기
해금·대금의 **흘러내림 글리산도 + 빠른 잘은 농현**으로 음성을 모사. 콧소리(비성)는
성악에서 — 기악만으로는 잘은 떪·하행 글리산도로 근사한다.

## 창작 처방
- 탄식·애상에. 선율을 **높은 데서 시작해 흘러내리게** 설계하고, 높은 음(라·도)의
  **격한 잘은 떪**을 표지로. 종지는 **레**로 떨어뜨린다.
- 기악만으로 쓸 땐 해금·대금의 빠른 잘은 농현 + 하행 글리산도로 서도색을 낸다.

## 흔한 오해 / 하지 말 것
- ✗ 남도식 굵고 느린 떪 — 서도는 **잘고 빠르다**(떪의 속도·폭이 정반대).
- ✗ 또렷한 강박 장단에 가두기 — 수심가류는 무장단·자유 리듬에 가깝다.
- ✗ 중심음을 아무 데나 — 서도는 **레로 흘러내려 종지**한다.
