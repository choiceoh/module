# 거문고 (玄琴) — 발현 현악기 (술대)

> 오른손 **술대**(15~17cm 대나무 막대)로 줄을 **치거나 뜯는** 6현 지터. 타현적 어택과
> 굵은 저음. 가야금(맨손)과 **혼동 금지**. 아래 상세는 국립국악원 「창작을 위한 국악기
> 이해와 활용」(거문고 편, 김준영) 기반 — 원문 비복제·요약. 인덱스 `00-index.md`,
> 확장 주법 개요 `extended-techniques.md`.

## 구조 — 6현(개방 4 + 운지 2), 16괘
- 긴 울림통(앞판 오동·뒤판 밤나무) 위 **16개 괘**와 **6현**. 굵은 줄(문현·대현·무현)과
  가는 줄(유현·괘상청·괘하청)이 **교대 배치**되어 극적인 음색 대비를 이룬다.
- **운지현(2)**: **유현(遊絃, 제2현·가는줄)**·**대현(大絃, 제3현·가장 굵은 줄)** 만 괘
  위를 왼손으로 짚어 선율을 만든다. **개방현(4)**: 문현(제1현)·괘상청(제4현)·괘하청
  (제5현)·무현(제6현)은 짚지 않고 연다. (유현·대현·괘상청은 괘 위, 문현·괘하청·무현은
  안족 위.)
- → 6현이지만 **선율 음역은 두 줄(유·대현)로 제한** — 기타와 달리 "두 줄만 짚는" 구조.
  개방현의 기능적 활용이 거문고 음악의 핵심.

## 발음·음색
- 오른손 술대로 줄을 **때리거나(타현) 뜯어** 강한 타악적 어택 + 여운. 지속이 짧아
  **빈 공간(여백)** 을 음악의 일부로 쓴다. 선비 악기로 통하는 장중·절제의 미감.
- 가야금보다 낮고 어둡다. 빠른 화려함보다 **굵은 점 + 여백**.

## 개방현의 기능 (★거문고 작곡의 관건)
- **문현(제1현, 굵고 장력 셈)**: ① 프레이즈·장단의 **시작**을 알리는 강한 어택(구음
  '흥/살/슬/싸'). ② 느린 곡에선 한 음을 받치는 **지속음**(여리게, 명상적·철학적 울림).
  ③ 창작에선 **지속저음·화성**으로도. 조현 대략 E♭2~G2.
- **무현(제6현)**: 프레이즈·악곡의 **마무리**(문현과 정반대 역할; 부드럽게). 조현
  대략 B♭1~D2.
- **괘상청(제4현)·괘하청(제5현)**: 전통에선 **같은 기준음(청)** 으로 조현하되 굵기·길이
  차로 **괘상청=부드럽고 탁함 / 괘하청=날카롭고 명료**의 음색 대비. 무현은 그 옥타브 아래.
  → 세 현(상·중·하 = 괘상청·괘하청·무현)을 연달아 쳐 종지. 창작에선 **서로 다른 음으로
  조현해 아르페지오·화성** 도 만든다.

## 술대 주법 (오른손)
- **살갱**: 문현 → **유현**으로 이어 침(문현이 1박 앞꾸밈). **슬기둥**: 문현 → **대현**
  (술대가 유현을 타고 넘어가며 경과음 발생).
- **뜰살**: 유현을 짧게 거슬러 뜯고 낚아채듯 문현을 쳐 **더 강하게**(살갱과 결합해 강조점).
- **싸랭**: 문현에서 유현까지 **한 번에 빠르게 그어** 강한 소리(변화/강조 지점에 절제해서).
- **스르렁**: 괘상청·괘하청·무현(또는 무현~대현/유현)을 **한꺼번에 빠르게 긁어 올리거나
  내림** — 산조·창작에서 적극(화살표 + 시작/끝 현 표기). 거문고 특유의 풍성한 음향.
- 타현 세기: **대점**(강)·**소점**(약), **술대 굴림/연타**(트레몰로성).

## 운지현 — 역안법(力按法)
- **역안법**: 줄을 **누른 채 밀어서** 음을 짚는다(17세기~ 기본). 음의 **생동감**(밀어
  올림·끌어내림·흔들기·굴리기)을 위한 선택 — 헤테로포니 합주에서 각 악기의 표정을 살림.
  대신 **정확한 음정·빠른 도약이 어렵다**. (가볍게 짚는 **경안법**은 특수한 경우만.)
- 유현은 왼손 **약지**로, 대현은 **중지**로 밀어 음을 만들고 검지·엄지로 괘를 짚는다.
- 농현·퇴성·추성·전성을 운지현에서. (가야금만큼 깊은 농현은 아니지만 밀고 끄는 표현 풍부.)

## 자세·기보
- **자세**: 정악(무릎)·산조(발)·창작(받침대; 의자/기립).
- **기보**: 정악=정간보. 창작=오선보 — 저음 담당 시 낮은음자리표, 고음은 높은음자리표
  (정대석은 옥타브 위 기보로 덧줄 절감), 음역 넓으면 큰보표. 개방현은 한자 **文/上/中/下**
  (문·괘상청·괘하청·무현) 또는 로마자 Ⅰ·Ⅳ·Ⅴ·Ⅵ 기호로 명시. 조현 음을 악보 앞에 지시.

## 화성·확장
- 개방현을 **서로 다른 음으로 조현**해 아르페지오·화음. 문현+괘상청/괘하청(괘상청을
  왼손 검지로 뜯어 화음), 유현·대현 동시(한 번의 술대질로 빠르게 두 줄). 술대 특성상
  완벽한 동시 화음은 어려워 부드럽게 울려 음량을 맞춘다.
- 타악적 주법(줄·통 두드림), 괘 사이 미분음, 하모닉스.
- **개량 거문고**: 이재화 **7현**(유현 2줄, 1990)→8·9현, 2001 **10현 '화현금'**으로
  음역·화음 확장(목적 있을 때만).

## 작곡 팁 (창작국악)
- 타현 어택을 **리듬 동인·구두점**으로(장구와 골격 박). **저음 골격·페달** 위에
  가야금·관악 선율을 얹어 대비.
- 문현 시작 / 무현·상중하 종지의 **개방현 구문**을 형식 표지로 활용.
- 굵은 점 + 여백의 설계가 본성에 맞다(빠른 멜리스마는 가야금/해금 몫).

## 창작 사례 (참고)
- 이성천 「인상」(1967): 서양식 작곡 개념의 **최초 거문고 창작 독주곡**. 정대석(열락·
  일출·달무리·무영탑 — 개방현 화성 적극), 이해식 「술대굿」.

## 흔한 오해 / 하지 말 것
- ✓ 술대는 **거문고가 맞다**(가야금엔 ✗). 단 가야금처럼 빠르고 섬세한 발현 패시지는
  기대 말 것(타현·역안법으로 둔중).
- ✗ 6현이니 6음 선율 자유 — **운지는 유·대현 2줄뿐**, 나머지는 개방현 기능.
- ✗ 깊고 빠른 농현 멜로디를 거문고 주역으로 — 가야금/해금의 몫.
