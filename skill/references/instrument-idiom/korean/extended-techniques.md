# 국악기 창작·확장 표현기법 — 개요

> sojeongcompose 원본 문서(SJY051 CC BY 자료 아님). 창작국악에서 쓰이는 **현대·확장
> 주법**의 공통 어휘와 분류. 악기별 상세는 각 악기 문서의 "창작·확장 표현기법" 절.
> 기본 주법·발음 수단은 `00-index.md`, 기보는
> `../../genres/creative-art-music/notation-for-players.md`.

## 1차 자료 (작곡가가 직접 볼 것)
국립국악원 악기연구소 **「창작을 위한 국악기 이해와 활용」** — **총론**과 악기별
(**가야금·거문고·대금·피리·해금·아쟁**)·부록으로, 구조·종류·연주법·연주곡 감상을
담은 **작곡가용** 자료(PDF·영상). 라이선스 **공공누리 제4유형**(출처표시·비상업·
변경금지)이니 **원문을 그대로 복제하지 말고** 작곡가가 직접 참조하라. 아래는 일반에
통용되는 기법 어휘를 sojeongcompose가 자체 정리한 것이다(학술 논문들로 교차확인).

## 분류 (현악 / 관악)
**현악기(가야금·거문고·해금·아쟁)** 의 확장 주법은 크게:
- **운지(왼손)** 계열: 하모닉스(harmonics), 글리산도/포르타멘토, 트릴·이중트릴,
  트레몰로, 미분음/사분음(누름·위치로), 클러스터.
- **운궁/발현(오른손)** 계열: 술 폰티첼로(sul ponticello, 브리지 근처), 술 타스토,
  **꼴 레뇨(col legno, 활대로)**, 루레(louré)·스타카토·마르카토·스피카토(찰현),
  타악적 주법(통·줄·복판 두드리기), 줄 긁기(스크래치), 발현↔찰현 전환.

**관악기(대금·피리·소금·단소·생황·태평소)** 의 확장 주법:
- **텅잉**: 플라터텅잉(flatterzunge, 혀 굴림)·더블텅잉. **중음/다중음(multiphonics,
  多衆音)**. **사분음·미분음**(운지·입김). 키 슬랩·숨소리(air tone)·성음 변화.
- 전통 시김새(시루·루러·농음·추성·퇴성)와 **연속선상**에서 확장된다(윤이상의
  오보에 기법과 피리 주법을 잇는 연구 등).

## 전통 시김새와의 관계 (중요)
확장 주법은 전통 시김새의 **대체가 아니라 확장**이다. 농현·꺾음 같은 고유 어법을
버리고 서양 특수주법만 얹으면 "국악기로 연주한 현대음악"이 된다 — 둘을 **잇는**
설계를 하라(→ `../../genres/creative-art-music/sigimsae-texture.md`).

## 기보·연주 가능성 (필수)
- 확장 주법은 **악기·연주자마다 가능 범위가 다르다.** 반드시 **연주 가능성을 연주자와
  합의**하고, 주법명+결과음+기보를 명시하라(→
  `../../genres/creative-art-music/notation-for-players.md`).
- 개량악기(25현 가야금·개량 거문고·개량 대금·대아쟁 등)는 **목적이 분명할 때만**.
