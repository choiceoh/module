# 소금 (小笒) — 가로 대나무 피리 (소형·고음)

> 대금의 소형·고음판. **청공이 없어 청(갈대막) 자체가 없다** → 맑고 또렷한 고음. 합주 고음 보강.
> 인덱스 `00-index.md`.

## 구조·발음
- 대금과 같은 가로 죽관이지만 작다. **청공이 없어 갈대막(청) 자체가 없다**(제작은 청공
  뚫는 단계를 빼면 대금과 거의 같다) → 청 울림 없이 깨끗한 음색.

## 음역·음색
- 대금보다 **한 옥타브가량 높은** 밝고 또렷한 고음. 합주에서 윗선을 또렷이.

## 작곡 팁 (창작국악)
- **고음 선율·윗성부 보강**. 대금과 옥타브/유니즌으로 겹쳐 광택, 또는 독립 고음선.
- 청 울림이 없어 대금보다 **차고 명료** — 투명한 텍스처가 필요할 때.
- 요성·혀치기·장식음 운용은 정악대금과 거의 같다(장식음이 풍부·화려하기도).

## 흔한 오해 / 하지 말 것
- ✗ 대금과 같은 청 울림 기대 — 소금은 **청공이 없어** 청 울림 자체가 없다.
