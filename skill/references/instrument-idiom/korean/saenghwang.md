# 생황 (笙簧) — 자유簧 (화음 가능)

> 여러 죽관 + 금속 자유리드. **국악기 중 유일하게 동시 2음(쌍성)의 화음**을 낸다(완전4·5도·
> 옥타브 위주). 들숨·날숨 모두 발음. 맑은 오르간 같은 지속음. 인덱스 `00-index.md`.

## 구조·발음
- 통(바람통)에 여러 개의 죽관을 꽂고 각 관 밑동의 **금속 자유황(free reed)** 이
  떨려 소리. 손가락으로 관의 구멍을 막아 해당 음을 울린다(전통 표준 **17관**; 개량형 24·37관).
- **두 관을 동시에** 막으면 **쌍성(2음 화음)**이 난다(전통은 완전4·5도·옥타브). 들숨·날숨
  양쪽으로 소리가 끊기지 않는 **지속**이 가능.

## 음색·음역
- 맑고 투명한, 하모니카·오르간을 닮은 지속음(음역은 관 수에 따라 다름).

## 작곡 팁 (창작국악)
- 단선율 일색의 국악기군에서 **화음(쌍성)**을 줄 수 있는 귀한 색. 전통 **쌍성(雙聲) 주법**은
  동시 **2음**(완전4·5도·옥타브 위주); 클러스터·드론 류는 개량·창작 확장(전통 근거 아님).
  4·5도 적층·빈 5도 지속음 등 창작 화성에 활용.
- **생소병주**(생황+단소)처럼 맑은 지속 + 점음 조합이 전통적.
- 단, 악기 구조상 **동시에 낼 수 있는 음 조합이 제한적** — 실제 가능한 화음을
  확인하고 지정하라(아무 화음이나 되는 게 아니다).

## 흔한 오해 / 하지 말 것
- ✓ 화음 가능(국악기 중 유일). 단 전통은 **쌍성=동시 2음**(완전4·5도·옥타브); **임의의
  화음이 다 되는 게 아님** — 관 배열에 따른 가능 조합 확인.
- ✗ 격렬한 농현·꺾음 — 자유황은 음높이 고정. 시김새는 다른 악기에.
