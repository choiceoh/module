# 피리 (觱篥) — 겹서(double reed) 원통 죽관

> **서(舌, 겹서)** 를 관대에 꽂아 부는 원통형 죽관. 크기 대비 **음량이 매우 크고** 배음이
> 강해 합주 선율의 **심지**. 아래 상세는 국립국악원 「창작을 위한 국악기 이해와 활용」
> (피리 편) 기반 — 원문 비복제·요약. 인덱스 `00-index.md`, 확장 주법 `extended-techniques.md`.

## 구조
- **서(舌)** + **관대**. 위아래 두 장의 **겹서(double reed)** 진동이 기주로 전달돼 소리.
  관대는 해죽(향·세피리)·황죽/오죽(당피리). 지공 **8개**(전면 7 + 후면 1; 당피리는 후공이
  제2공).
- 리드가 악기 대비 커서 **취법(서 무는 법)** 의 비중이 크다 — 피리 이해의 핵심.

## 종류
- **향피리**(가장 보편): 관현합주·관악합주·무용반주 등 대부분에 편성. 관대 종류 = 정악용·
  산조용·**창작음악용(신곡관대)**. 창작에선 정악용 + **창작음악용**(가장 보편)을 쓴다.
- **세피리**: 작고 음량이 작으며 음색이 **부드럽다** — 줄풍류·노래반주, 창작에서 여린 음색.
- **당피리**: 전통 피리 중 **음량이 가장 크나 거칠고 탁함**(종묘제례악 등). 지공 배열이
  달라 **운지·음역이 향피리와 다르다** → 아래 향피리 기준 음역/취법 수치를 당피리에 그대로
  적용하지 말 것. 고음역은 서 압력을 조절하는 **'비청(飛淸)'/역취**로 연주하므로(자료상
  청중려 F5 이상), 중·고음역 진행은 **연주 가능성을 연주자와 확인**하라.
- **개량 고음피리**(1999 개량): '꼭두청 키'(레지스터 키)로 **역취 음역을 원활하게** —
  음역 확대. 현재 **창작에서 가장 보편**. (키 제외하면 창작음악용 관대와 동일.)

## 취법·음역 (★작곡 시 핵심)
- **보통물기 / 조여물기**(음 올림·작은 음량) / **풀어물기**(음 내림·큰 음량). 피리는 음고
  **유동성**이 커 **취법에 따라 음고·음색이 달라진다**.
- **향피리에서 남려(C5)~청태주(F5) 구간은 한 운지법에서 취법만으로** 연주 → 이 음역의
  음들은 트릴·트레몰로가 어렵고 빠른 연주가 불리하다(작곡 시 세심히 고려).
- **F5 이상 고음역은 역취(over blowing)** — 불안정·날카로움(고음피리는 이를 보완). 취법
  활용으로 12반음 가능하나 C5~F5는 취법 의존.

## 전통/경과 주법 (음 이동 과정에서 나옴)
- **서침표**: 혀로 서를 간결하게 침(주로 제1공 음; 남려 C5·임종 B♭4 종지에).
- **올리더름 / 내리더름**: 주음 ↔ 완전4도 위 음 사이. 상행=올리더름, 하행=내리더름(거쳐
  가는 음을 동반).
- **루러**: 장2도 아래 음을 강조한 뒤 시작음으로 돌아오는 진행에.

## 시김새
- **농음**(굵은 농음/잔농음), **추성**(운지 그대로 취법·호흡으로 밀어 올림 — 표현 자유),
  **퇴성**, **요성**(밀어 올려 떪), **꺾는음**(육자배기토리). 피리는 한 운지에서 여러 음고가
  나와 추성·요성 표현이 자유롭다.

## 현대 주법 (피리 편 정리; 주로 고음피리 기준)
- **트릴·트레몰로**(단, C5~F5는 취법 의존이라 어려움), **스타카토**(스타카티시모~메조;
  호흡 또는 혀로 리드 막음), **텅잉**(싱글 tu/ru[주력]·더블 tu-ku·플러터[간헐]·트리플
  tu-ku-tu), **글리산도/포르타멘토**(농음 포함/비포함 선택), **서(舌) 주법**(리드만 분리해
  연주 — 이해식 「피리를 위한 호드기」 1984), **다음주법(multiphonics)**(배음; 리드라 잡음
  동반·고음역 역취서 원활), **순환호흡**(리드가 커 쉽지 않음).

## 작곡 팁
- **강한 선율 외침·합주 심지·거친 색채**에. **과용 금지** — 적게 써도 텍스처를 장악한다.
  여린 대목은 **세피리**, 고음역·창작 편의는 **고음피리**.
- 입술 압력의 음정 휨·요성을 자원으로. 전통 시루·서침표·루러의 연장선에서 현대 주법으로.

## 흔한 오해 / 하지 말 것
- ✗ "작으니 음량도 작겠지" — **반대로 매우 크다**(밸런스 주의).
- ✗ 일반 화음(코드처럼 동시) — 단선율. 단 **다중음(multiphonics)** 은 특수주법으로 예외 가능.
- ✗ C5~F5 음역에 빠른 트릴·트레몰로 — 한 운지·취법 의존이라 어렵다.
