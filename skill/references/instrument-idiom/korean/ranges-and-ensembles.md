# 음역·이조 빠른표 + 편성 레시피 (작업용)

> sojeongcompose 원본 문서(SJY051 CC BY 자료 아님). **편성을 짤 때 한눈에 보는 표**.
> 악기별 상세(주법·시김새·확장주법)는 각 악기 문서, 인덱스는 `00-index.md`, 관현악 밸런스는
> `../../genres/creative-art-music/gugak-orchestration.md`.
> ⚠ **음역은 대략치다.** 곡·유파·개량 정도·연주자에 따라 다르고, 창작곡은 조현(scordatura)을
> 새로 지정하는 일이 흔하다. 주법·편성을 지시하기 전 **해당 악기 문서를 반드시 확인**하라.

## 음역·이조 빠른표 (실음, 근사)
| 악기 | 음역(대략) | 이조·조현 | 발음/주의 |
|---|---|---|---|
| 가야금(25현) | **G2~D5** (~2.5옥) | 조현 자유(scordatura) | 맨손 발현. 창작 표준. 12현(법금·산조)은 더 좁고 낮음 |
| 거문고 | 저음~중음(선율은 **유·대현 두 줄**) | 괘·조현 | **술대** 타현. 정확 음역은 곡·괘에 따라 |
| 해금 | **약 3옥타브**(무포지션 ~1.5옥) | 개방현 조율로 **자유 이조** | 활(찰현). 시김새=활 압력·운지 |
| 아쟁 | **최저음부**(산조아쟁/대아쟁) | — | 활(찰현). 합주 베이스, 한 줄로 굵게 |
| 양금 | **E♭3~A♭5** (~2.5옥) | 고정(개방, **농현 불가**) | 타현 금속성·빠른 감쇠 |
| 대금 | **B♭3~E6**(창작 ~A♭6) | 정악대금 **B♭관** | 입김(저·평·역취). 역취 고음 강함 |
| 소금 | 대금보다 **~1옥 위** | | 고음 윗선 보강 |
| 단소 | 중~고 **~2옥** | | 여린 음량·청아 |
| 피리(향) | ~2옥(**C5~F5 취법**, F5↑ 역취) | 이조악기 | 겹서. **음량 큼**(뚫는다) |
| 태평소 | **A♭4~E♭6** (~1.5옥) | **전통 율 기반**(평균율과 어긋남) | 매우 강·날카로움 |
| 생황 | 관 수에 따라 | | **화음(쌍성) 지속 가능**(유일) |
| 성악 | 정가·판소리·민요(발성 상이) | — | `vocals.md` |

> 화음 산출: 가야금=겹뜯기로 제한적·곧 감쇠, 거문고=두 줄, **생황=지속 화음 가능**.
> 단선율 관악기(대금·피리…)는 일반 화음 불가(특수주법 멀티포닉스는 예외).

## 편성 레시피 (전통 → 창작 출발점)
**전통 편성을 골격으로 삼고, 창작에선 음역 분산·저음 단선(→ `gugak-orchestration.md`)을 지켜라.**

### 독주 + 고수
- **산조**: 독주악기(가야금/거문고/대금/해금/아쟁) **1 + 장구(고수)**. 한배 점층이 형식
  (→ `../../genres/sanjo/00-index.md`·`../../genres/creative-art-music/jangdan-patterns.md`).

### 풍류방(정악) 실내악
- **줄풍류(현악영산회상)**: 거문고·가야금·해금·대금·세피리·단소·장구(+양금). 현 중심·담백.
- **삼현육각(대풍류)**: 향피리 2·대금·해금·장구·좌고(북). 관 중심·웅장. 행악·무용 반주.
- **가곡/정가 반주**: 거문고·가야금·세피리·대금·해금·단소·장구.

### 민속·타악
- **사물놀이**: 꽹과리·징·장구·북(금속+가죽 4). 짝드름·점층(→ `samul-metals.md`·`buk.md`).
- **시나위**: 대금·피리·해금·아쟁·(가야금·거문고)+장구·징. **즉흥 합주(헤테로포니)**
  (→ `../../genres/sinawi.md`).

### 창작 실내악(출발점 예)
- **25현가야금 + 해금 + 대금 + 타악**: 발현+찰현+관+구문. 음역 잘 분산됨.
- **거문고 + 아쟁 + 장구**: 타현 어택 + 저음 지속 + 구문. 저음 골격 텍스처.
- **동질악기 앙상블**(예: 산조가야금 3, 거문고 다중): 한 음색의 헤테로포니
  (→ `../../genres/creative-art-music/recent-trends.md`).

### 국악관현악(대편성)
- 파트: **피리·대금(+소금)·해금·가야금·거문고·아쟁·타악**(+개량 저음 대아쟁·25현).
  좌석·밸런스·저음 처리는 `../../genres/creative-art-music/gugak-orchestration.md` 및
  `../../genres/gugak-orchestra.md`.

## 빠른 결정 체크
- **저음**은 아쟁/대아쟁/25현 저현으로 **한 줄 굵게**(화성 쌓지 말 것).
- **윗선**은 소금·대금·피리. 피리·태평소는 **과용 금지**(강하게 뚫는다).
- **지속음**이 필요한데 발현악기뿐이면 → 찰현(해금·아쟁)·생황·연음으로 대체.
- **화음 지속**이 필요하면 → 생황(유일) 또는 찰현 중첩/헤테로포니.
