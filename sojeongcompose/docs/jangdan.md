# 장단(長短) 설계 — 드럼셋 매핑과 패턴

장단은 `plugins/jangdan` QML 플러그인으로 입력하고, 장구/북 보표의
**드럼셋(Drumset)** 음고에 매핑해 재생한다.

## 장구 주법(구음) → 드럼셋 라인

`plugins/jangdan/patterns.js` 의 `STROKE` 값을, 포크의 장구 Drumset 정의와
**같은 MIDI 음고**로 맞춘다(현재 값은 GM 타악 근사 placeholder).

| 구음 | 의미 | 연주 | placeholder MIDI |
|---|---|---|---|
| 덩 (deong) | 합장단 | 북편+채편 동시 | 36 |
| 쿵 (kung) | 북편 | 왼손(궁편) | 35 |
| 덕 (deok) | 채편 | 오른손(열편) | 38 |
| 기덕 (gideok) | 겹채/꾸밈 | 채편 겹타 | 40 |
| 더러러러 (deoreoreo) | 굴림 | 채편 롤 | 42 |

> 확정 절차: 포크 `share/instruments` 의 장구 항목에 `<useDrumset>1</useDrumset>`
> 과 `<Drumset>`(각 음고의 name/노트헤드/스템 방향)을 정의하고, 그 음고를
> `patterns.js` 의 `STROKE` 와 일치시킨다.

## 수록 장단

| key | 이름 | 박자 | 성격 |
|---|---|---|---|
| `gutgeori` | 굿거리 | 12/8 | 흥겹고 유연한 4박 |
| `jajinmori` | 자진모리 | 12/8 | 빠르게 몰아가는 4박 |
| `semachi` | 세마치 | 9/8 | 3박(아리랑 등) |
| `jungmori` | 중모리 | 12/4 | 느긋한 12박 |

후속 추가 예정: 진양조(18/8), 중중모리(12/8), 휘모리, 엇모리(10/8) 등.
패턴 타점은 대표형이며, 변주/맺음형은 작곡가 검토 후 보강한다.

## 플러그인 동작 메모

- 선택된 보표(없으면 곡 처음)부터 지정 마디 수만큼 패턴을 삽입한다.
- 현재 스캐폴드는 쉼표 입력을 placeholder 로 처리한다. 실제 장치에서 MuseScore
  버전의 `cursor.addRest` 등 API 거동을 확인해 교체한다(jangdan.qml 의 TODO).
- 박자표 자동 설정은 후속(현재는 사용자가 해당 마디 박자를 장단 박자와 맞춤).
